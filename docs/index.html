原文与译文，一起读

Foxtranslate 是开源双语翻译扩展。在浏览器里阅读外文网页、翻译文档和字幕，把遇到的生词留下来复习。

下载安装包 安装说明

支持 Chrome / Edge 140 及以上版本。免费引擎可直接使用，界面提供简体中文和英语。

网页阅读

逐段查看原文和译文，划选文字选择目标语言与引擎，也可使用右键、悬停和输入框翻译。

文档与字幕

翻译 PDF、电子书与办公文档，校订后下载。视频和会议翻译使用平台提供的字幕。

生词复习

保存生词、例句和来源页面，通过 FSRS 闪卡复习，在阅读中积累自己的词汇。

选择服务，管理数据

内置 Google、Microsoft 和 MyMemory 免费翻译，也可连接 Foxmori 订阅或配置自己的翻译服务。服务商可能另行收费。设置、密钥、生词和缓存保存在浏览器本地，翻译和 AI 功能会将所需文本发送到对应服务。详情见隐私政策。

Open-source bilingual reading

Translate web pages, selected text, documents and available captions. Save vocabulary with context and review it with spaced-repetition flashcards. Built-in free engines work without an account. Optional providers may charge for their services. Read the privacy policy for data handling details.
