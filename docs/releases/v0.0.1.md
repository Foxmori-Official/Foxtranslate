Foxtranslate 的首个公开版本适用于 Chrome 和 Edge。用它双语阅读网页、翻译字幕和文档，并把遇到的生词留到闪卡里复习。

## 主要功能

- 网页支持双语对照与仅译文，以及划词、悬停和输入框翻译。
- 点击 YouTube 播放器的狐狸图标开启字幕翻译。Google Meet、Microsoft Teams 和 Zoom 网页端可翻译会议平台提供的字幕。
- 文档翻译支持 PDF、EPUB、DOCX、PPTX、XLSX、HTML、JSON、Markdown、TXT、SRT、VTT 和 ASS，可在导出前逐段校订。
- 划词时可收藏生词与例句，使用 FSRS 闪卡复习到期词汇。
- Google、Microsoft 和 MyMemory 无需配置密钥。可按需配置 DeepL、OpenAI 兼容接口、DeepSeek、Claude、Gemini 或 LibreTranslate。

## 安装

1. 下载 [foxtranslate-0.0.1.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.1/foxtranslate-0.0.1.zip) 并解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择「加载已解压的扩展程序」，定位到包含 `manifest.json` 的文件夹。
3. 完成安装引导，打开普通网页，点击工具栏中的 Foxtranslate 开始翻译。更新后刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.1/SHA256SUMS.txt)。

## 使用边界

- YouTube 普通视频需要可读取的字幕轨，会议字幕需要先在平台内开启。
- PDF 需要可提取的文本。导出格式为 HTML，支持双语和仅译文。
- 付费和自建服务的认证、可用性和用量以该服务的配置为准。
