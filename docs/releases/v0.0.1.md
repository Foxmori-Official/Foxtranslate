## 中文

Foxtranslate 的首个公开构建版本，适用于 Chrome 和 Edge。

### 主要功能

- 整页双语对照、仅译文、划词、悬停和输入框翻译。
- 网页、文档、生词复习、设置与安装引导采用左右布局，使用 Foxmori 配色和狐狸图标。
- YouTube 播放器与网页悬浮入口使用扩展图标，支持字幕开关、切视频、播放器重建和状态反馈。
- 支持 PDF、EPUB、DOCX、PPTX、XLSX、HTML、JSON、TXT、Markdown、SRT、VTT、ASS 文档翻译、导出和校订。
- 提供免费翻译引擎、可配置的 AI 与付费服务、生词本和 FSRS 闪卡。
- 完善引导保存反馈、下拉菜单键盘操作、视频设置和站点规则。
- 提供六个参考项目的更新报告、持续集成和发布流程。

### 安装

1. 下载本页的 `foxtranslate-0.0.1.zip` 并解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式。
3. 选择“加载已解压的扩展程序”，定位到包含 `manifest.json` 的解压目录。
4. 完成首次安装引导，打开普通网页后点击扩展开始翻译。

`SHA256SUMS.txt` 提供安装包的 SHA-256 校验值。GitHub 自动提供的 Source code 压缩包用于获取源码，安装扩展请使用 `foxtranslate-0.0.1.zip`。

### 验证与限制

发布流程执行类型检查、606 项自动化测试、浏览器集成测试、构建和安装包检查，覆盖图标加载、引导保存、左右布局、键盘选择、网页翻译与恢复、文档导出、生词复习和 YouTube 控件生命周期。

YouTube 需要视频提供可读取字幕轨。字幕处理与服务协议使用可控数据测试，真实页面另行检查播放器入口。付费服务需要自行配置 API Key。PDF 当前导出为双语 HTML，扫描件 OCR 和保留原 PDF 版式的导出尚未实现。

### 参考与维护

参考 KISS Translator、FluentRead、Read Frog、Interline、OpenImmersive Translator 和 MTranBrowser。具体参考方向、许可证和更新流程见仓库 README、THIRD_PARTY_NOTICES.md 与 docs/UPDATING.md。

## English

The first public build of Foxtranslate for Chrome and Edge.

### Features

- Bilingual and translation-only webpages, selection, hover and input translation.
- Left navigation beside the workspace across pages, documents, vocabulary, settings and setup, with Foxmori colors and fox icons.
- The extension icon in YouTube and the floating webpage control, with caption toggling, video navigation recovery and status feedback.
- Translation, export and post-editing for PDF, EPUB, DOCX, PPTX, XLSX, HTML, JSON, TXT, Markdown, SRT, VTT and ASS.
- Free translation engines, configurable AI and paid services, vocabulary and FSRS flashcards.
- Setup save-error feedback, keyboard-operable dropdowns, video settings and site policies.
- Review reports for six reference projects, CI and release builds.

### Installation

1. Download and extract `foxtranslate-0.0.1.zip` from this release.
2. Open `chrome://extensions` or `edge://extensions` and enable Developer mode.
3. Choose Load unpacked and select the folder containing `manifest.json`.
4. Complete setup, open a normal webpage and use the extension to translate it.

`SHA256SUMS.txt` contains the package checksum. GitHub’s Source code archives contain the source tree. Install the built extension with `foxtranslate-0.0.1.zip`.

### Verification and limitations

The workflow runs type checking, 606 automated tests, browser integration tests, the build and package verification. Tests cover icons, setup, persistence, layouts, keyboard selection, page translation and restoration, document export, vocabulary review and YouTube control lifecycle.

YouTube requires readable caption tracks. Caption processing and provider protocols use controlled test data, and the player entry is also checked on a live page. Paid providers require your own API key. PDF exports as bilingual HTML. Scanned-document OCR and PDF export retaining the original layout remain outside the current implementation.

### References and maintenance

The project draws on KISS Translator, FluentRead, Read Frog, Interline, OpenImmersive Translator and MTranBrowser. See the repository README, THIRD_PARTY_NOTICES.md and docs/UPDATING.md for attribution, licensing and maintenance.
