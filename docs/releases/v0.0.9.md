本次更新将 Foxmori 账户接入迁移到通用密钥接口，减少重复请求和设置页面刷新。

### Foxmori 账户与密钥

- 点击「连接已登录账户」时才读取主站账户和可用套餐。重新打开或切回设置时显示上次连接的信息，不再自动反复连接。
- 创建密钥时默认名称为 Foxtranslate，成功后直接更新密钥和模型字段，保留当前设置界面。
- 建钥结果不明确时，通过主站密钥列表核对，避免自动重复创建。
- 已保存的有效 API Key 可直接使用，也可手动填写或共用密钥。主站退出登录后，扩展仍可用有效密钥翻译。
- 建钥等待期间手动保存的新密钥会被保留，晚到的创建响应不会将其覆盖。

### 安装与升级

- 使用 Chrome 或 Edge 140 及以上版本，下载并解压 [foxtranslate-0.0.9.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.9/foxtranslate-0.0.9.zip)。
- 初次安装时，在扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
- 覆盖升级时，将新版文件复制到原扩展目录，在扩展管理页点击「重新加载」，然后刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.9/SHA256SUMS.txt)。
