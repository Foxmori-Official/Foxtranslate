本次更新完善划词翻译、Foxmori 服务配置和设置导航，并调整 YouTube 字幕读取与翻译调度。适用于 Chrome 和 Edge。

## 本次更新

- 划词卡片顶部可选择目标语言，底部可选择免费引擎、已配置的 AI 服务和自定义引擎。切换后立即重新翻译当前选文，选择作用于当前卡片。
- 快速切换语言或引擎时保留最新请求的译文。显式选择引擎后，该服务失败会在卡片中显示错误，可继续切换引擎重试。
- 可连接已登录的 Foxmori 账户，选择套餐分组、创建密钥并获取可用模型。修复 AI 解析和多轮追问的响应处理。
- 设置侧栏按“词汇与隐私 → 文档翻译 → 生词复习 → 主站与帮助链接”排列，文档翻译和复习入口独立展示。
- YouTube 字幕跟随播放器当前 CC 轨道，补齐授权参数、空响应重试和切换字幕语言后的重新读取。
- 字幕按播放位置预取，拖动进度条后优先翻译新位置的当前句。播放器狐狸按钮显示开启状态。
- 优化紧凑弹窗和工作区导航，修复生词保存时的界面语言同步及复习评分反馈。

## 安装与更新

1. 下载 [foxtranslate-0.0.2.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.2/foxtranslate-0.0.2.zip) 并解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，定位到包含 `manifest.json` 的文件夹。
3. 已安装的用户可把新文件覆盖到原扩展目录，点击扩展管理页的重新加载，再刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.2/SHA256SUMS.txt)。

## 验证与使用边界

- 600 项自动化测试，以及使用模拟翻译服务的浏览器验收通过，覆盖语言和引擎切换、过期请求处理、字幕授权、选轨和拖动进度后的翻译优先级。
- 真实 YouTube 字幕依赖视频提供可读取的 CC 轨道。测试环境中部分视频的原生 CC 请求返回空内容，这些视频尚未完成真实字幕读取验收。遇到读取失败时，请先检查播放器的原生 CC。
- 免费和付费翻译服务的可用性、模型速度、额度与限流以所选服务为准。AI 服务需配置密钥和可用模型。
- PDF 需要可提取的文本，翻译后导出为 HTML。网页会议需要先开启会议平台的字幕。
