本次更新修复微软免费翻译和整页翻译切换引擎后的重试问题。

### 网页翻译

- 更新微软翻译接口，修复旧认证地址返回 HTTP 404 导致翻译失败的问题。
- 切换默认翻译引擎时，已打开的网页会保留成功译文，并按新设置重试失败和正在翻译的段落。
- 免费引擎暂时不可用时，显示各引擎的失败原因和冷却等待时间。回退时跳过仍在冷却的引擎，减少大量网页同时翻译时的重复失败请求。

### 安装与升级

- 使用 Chrome 或 Edge 140 及以上版本，下载并解压 [foxtranslate-0.0.10.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.10/foxtranslate-0.0.10.zip)。
- 初次安装时，在扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
- 覆盖升级时，将新版文件复制到原扩展目录，在扩展管理页点击「重新加载」，然后刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.10/SHA256SUMS.txt)。
