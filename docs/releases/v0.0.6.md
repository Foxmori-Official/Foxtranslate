本次更新修复了连接 Foxmori 后切换账号可能拿到其他账号密钥的问题。

### 账户连接与密钥

- 点击「创建 Foxmori 密钥」时，主站会核对连接的账号和所选套餐，只把 Foxtranslate 需要的密钥发给扩展。扩展无需读取完整密钥列表。
- 切换账号后，按提示重新连接。登录过期时请重新登录，套餐不可用时请查看主站提示。这些情况都会保留扩展里已经保存的密钥。

### 安装与升级

- 使用 Chrome 或 Edge 140 及以上版本，下载并解压 [foxtranslate-0.0.6.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.6/foxtranslate-0.0.6.zip)。
- 初次安装时，在扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
- 覆盖升级时，将新版文件复制到原扩展目录，在扩展管理页点击「重新加载」，然后刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.6/SHA256SUMS.txt)。
