本次更新修复 Foxmori 账户连接后切换账号可能使用错误密钥的问题，并缩小扩展读取的密钥范围。

## 账户连接与密钥

- 点击“创建 Foxmori 密钥”时，扩展从主站标签页向专用接口提交已确认的账号和所选套餐。主站用同一登录会话校验账号和套餐，并返回这一把扩展密钥。
- 账号切换时提示重新连接。登录过期时提示重新登录。套餐不可用时显示主站提示。请求失败时保留现有密钥。
- 扩展通过账号资料和可用套餐接口连接账户，密钥通过专用接口取得。其他应用的密钥不会传给扩展。

## 安装与更新

1. 使用 Chrome 或 Edge 140 及以上版本。
2. 下载 [foxtranslate-0.0.6.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.6/foxtranslate-0.0.6.zip) 并解压。
3. 新安装时，在扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。覆盖升级时，替换原目录中的文件并重新加载扩展。
4. 刷新已打开的网页。需要重新配置 Foxmori 密钥时，请先连接当前登录账号。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.6/SHA256SUMS.txt)。
