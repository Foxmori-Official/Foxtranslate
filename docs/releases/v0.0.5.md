本次更新开放翻译并发设置，解除整页翻译固定同时处理 4 段的限制，并为翻译性能参数提供建议范围和调整提示。最低需要 **Chrome / Edge 140**。

## 并发与批量翻译

- 在“设置 → 翻译引擎 → 翻译性能”调整并发请求数，允许 1～8，默认 3。同一服务账户在各页面间共享实际网络请求上限。
- 整页翻译按所选并发数投递任务。支持批量翻译的 AI 引擎按并发数与每批条数共同安排段落，让后台能够组成多个批次。
- 每批最大条数允许 1～32，默认 8。界面输入及配置读写校验范围；并发限制同时在网络调度层执行。
- 修改设置后后续任务采用新值，在途任务自然完成。降低上限不会强制中断已经发起的请求。
- 保留可见区域优先、当前字幕优先调度及服务端限流后的冷却处理。

## 参数使用建议

| 参数 | 建议范围 | 默认值 |
| --- | --- | --- |
| 并发请求数 | 2～5，且不超过服务商上限 | 3 |
| 每批最大条数 | 4～8 条 | 8 |
| 每批最大字符数 | 800～2000 字符 | 1200 |
| 聚合间隔 | 80～200 毫秒 | 120 |

AI 引擎建议开启批量翻译；免费引擎或遇到限流时，并发建议降至 1～2。各项设置下方提供默认值、建议范围及何时调大或调小的提示，支持简体中文、英文和窄屏显示。

这些范围是日常使用起点，实际速度取决于模型、文本长度、网络与服务商限制。批量结果会在对应批次返回后显示，并发不等于逐字流式输出。

## 安装与更新

1. 确认浏览器为 Chrome / Edge 140 或更高版本。
2. 下载 [foxtranslate-0.0.5.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.5/foxtranslate-0.0.5.zip) 并解压。
3. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，定位到包含 `manifest.json` 的文件夹。
4. 已安装的用户覆盖原扩展目录，在扩展管理页重新加载，再刷新网页。已有配置和生词保存在本机。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.5/SHA256SUMS.txt)。
