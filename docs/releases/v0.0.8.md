本次更新扩大了网页预翻译范围，加入全页失败重试和翻译缓存清理，并改善了 Foxmori 账户连接。

### 网页翻译

- 提前翻译视口上下各 1200 像素内的内容，为滚动阅读留出更多等待时间。
- 点击任一失败段落的重试按钮，可重试本页全部失败内容。
- 翻译引擎请求超时固定为 600 秒，设置页移除超时输入框。
- 修复修饰键悬停翻译的触发问题。关闭自动划词翻译后，仍可通过右键翻译选中的文字，译文框出现在选区附近。

### 账户与隐私

- 改善 Foxmori 登录入口和旧标签页的连接恢复。在设置中查看当前登录账户或上次连接账户，翻译仍使用独立配置的 API Key。
- 建钥期间手动修改 API Key 后，扩展会保留手动保存的值。
- 在「设置 → 隐私」中可以清除翻译缓存。

### 安装与升级

- 使用 Chrome 或 Edge 140 及以上版本，下载并解压 [foxtranslate-0.0.8.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.8/foxtranslate-0.0.8.zip)。
- 初次安装时，在扩展管理页开启开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
- 覆盖升级时，将新版文件复制到原扩展目录，在扩展管理页点击「重新加载」，然后刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.8/SHA256SUMS.txt)。
