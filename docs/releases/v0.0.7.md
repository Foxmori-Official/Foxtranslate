- 点击「检查更新」查询 GitHub 最新正式版。发现新版时，可以打开对应的发布页查看说明并下载安装包。

## 安装与升级

使用 Chrome 或 Edge 140 及以上版本，下载并解压 [Foxtranslate v0.0.7 安装包](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.7/foxtranslate-0.0.7.zip)。

- 初次安装时，在浏览器扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，选中包含 `manifest.json` 的文件夹。
- 覆盖升级时，将文件复制到原扩展目录，在扩展管理页点击「重新加载」，然后刷新已打开的网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.7/SHA256SUMS.txt)。
