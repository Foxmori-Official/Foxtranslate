本次为安全与性能修复版本，修复网页伪造操作触发付费请求、引擎切换后沿用旧配置、失败回退并发放大及生词高亮反复重建的问题。适用于 Chrome 和 Edge。

## 安全修复

- 划词翻译由真实鼠标选取或键盘选择触发，程序自动设置的选区不会启动翻译。
- 输入翻译、悬停、快捷键、悬浮球、对比翻译和字幕控件拒绝网页脚本伪造的操作；真实用户的语言/引擎切换、AI 解析及追问仍可正常使用。
- 更换引擎端点、密钥、模型或提示词后，新请求使用新配置，缓存同步隔离，防止后续文本发送到旧服务。缓存键不包含原始密钥。

## 性能改进

- 批量翻译、单条回退、AI 解析、追问及术语提取共用服务账户的并发限制；同一端点账户的不同模型和自定义引擎实例共享预算。
- 只有成功响应的批量格式不符合要求时才尝试单条回退，回退请求也受并发限制。鉴权失败、限流和服务错误直接返回，避免请求数量扩大；429 根据 Retry-After 冷却，当前字幕在等待队列中优先。
- 翻译字数在独立存储中汇总写入，自动读取旧版累计统计，不再向所有网页广播整份配置。
- 生词高亮仅在相关设置或生词数据变化时刷新，关闭高亮后过期的异步结果不会重新添加标记。

## 安装与更新

1. 下载 [foxtranslate-0.0.3.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.3/foxtranslate-0.0.3.zip) 并解压。
2. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，定位到包含 `manifest.json` 的文件夹。
3. 已安装的用户可把新文件覆盖到原扩展目录，在扩展管理页点击重新加载，再刷新已打开的网页。原设置、生词本和累计翻译统计会保留。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.3/SHA256SUMS.txt)。

## 验证与使用边界

- 619 项自动化测试、类型检查及两组隔离浏览器验收通过，覆盖正常翻译流程、伪造事件拦截、配置与缓存隔离、并发限制、限流冷却、统计迁移和高亮稳定性。
- 安全与翻译测试使用虚假凭证及模拟服务，没有向真实付费模型发送测试请求。服务端鉴权、计费和账户级限流不在本扩展仓库的验证范围内。
- 真实 YouTube CC 在此前测试环境中部分视频返回空内容，这些视频的真实字幕读取仍待验收；本次更新未改变该使用边界。
- 模型速度、额度和限流以所选服务为准。共享预算限制同时在飞的请求，不代表服务商的每分钟额度。
