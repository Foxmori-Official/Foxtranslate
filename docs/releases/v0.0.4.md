本次更新修复独立审查发现的 11 项隐私、功能与性能问题，并整合此前已合入主分支的安全加固和中英文界面调整。最低需要 **Chrome / Edge 140**。

## 隐私与安全

- 网页长段落在后台完整脱敏后再切分，避免跨分段的银行卡号、格式化电话和多行私钥避开检测；隐私、术语和行内占位符保持完整，结果受控还原。
- 网页内容脚本通过精简配置获取所需设置，无法访问完整密钥存储或管理接口。本地存储限制在扩展自身界面和后台；最低浏览器版本与这个隔离接口的实际支持一致。
- 待译文本、页面上下文、语言检测及 AI 输入支持本地脱敏。自定义接口检查 HTTP(S) 地址和主机访问权限，凭证请求限制重定向。

## 功能修复

- 输入翻译返回后检查请求顺序和编辑状态，保留用户继续输入的内容；迟到译文提供预览及复制。
- 会议字幕切换目标语言或引擎后重置会话，旧请求不能写入当前缓存或覆盖新字幕。
- 网页段落原地更新或复用 DOM 节点后重新翻译，迟到结果不会覆盖新内容；关闭整页翻译后停止后续分段调度。
- HTML 和 EPUB 每次从原件生成导出文件，重复下载、校订或切换输出模式不会叠加译文或丢失原文。
- DOCX 导出保留译文的换行和制表符；顶层字符串 JSON 可以正确导出译文。
- PDF 使用匹配的兼容运行时和 worker，按需加载，其他文档格式打开时不加载完整 PDF 引擎。
- 扩展界面只提供简体中文和 English，支持跟随系统；移除其他语言资源及旧界面语言设置的迁移逻辑。翻译的源语言和目标语言仍独立选择。

## 性能改进

- 大页面初始扫描按时间预算分片执行，接近视口时再进行文本抽取和语言检查；动态内容按变更范围扫描。
- 脱敏重叠检查改为有序区间合并，避免逐个实体遍历全部旧记录。
- 批处理队列空闲后释放配置与上下文闭包，配置轮换时不会删除仍在运行的新队列。
- 术语匹配器及有效术语表复用，改进中日韩术语边界与最长重叠匹配，术语变化后正确隔离缓存。

## 安装与更新

1. 确认浏览器为 Chrome / Edge 140 或更高版本。
2. 下载 [foxtranslate-0.0.4.zip](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.4/foxtranslate-0.0.4.zip) 并解压。
3. 打开 `chrome://extensions` 或 `edge://extensions`，开启开发者模式，选择“加载已解压的扩展程序”，定位到包含 `manifest.json` 的文件夹。
4. 已安装的用户可覆盖原扩展目录，在扩展管理页重新加载，再刷新网页。

安装包校验值见 [SHA256SUMS.txt](https://github.com/Foxmori-Official/Foxtranslate/releases/download/v0.0.4/SHA256SUMS.txt)。
